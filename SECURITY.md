# Security Policy

## Supported version

Security fixes are applied to the latest `main` and the deployed
`https://lioncc.ai` site.

## Report a vulnerability privately

Do not open a public issue for a vulnerability or include customer data,
payment details, credentials, or private invitation links. Use GitHub private
vulnerability reporting from the repository Security tab. If that option is
unavailable, contact the repository owner through a private GitHub channel.

## In scope

- exposure of credentials or secrets in the repository or deployment;
- unauthorized changes to the production publication path;
- a broken domain, certificate, or redirect that exposes another origin;
- a cross-site scripting or unsafe external-link issue on a public page;
- accidental publication of local files, customer data, or private media.

## Safe reports

Use the public production URL only for non-destructive checks. Do not attempt
to access customer accounts, payment systems, or private dashboards. Redact
personal data and tokens from screenshots and logs.
