开始前

先确认这三项

01

先登录 Grok 账号

使用你准备充值的 Grok 账号登录 grok.com，先确认账号能正常进入。

02

确认是否支持 Grok Bot

登录后先确认该账号是否支持 Grok Bot，避免充值时覆盖已有账户权益。无法确认时先暂停提交并核实，充值后的功能演示另见最后一步。

03

准备可用卡密

充值前准备好对应套餐的卡密。Session JSON 只在当前操作中使用，不要发给他人。

图文步骤

完整图文步骤

01

打开充值系统

先完成上方账号检查，再打开 grok.subcheap.free/gr/zh。页面四步依次为：输入卡密、输入 userId / Session、确认充值、完成。

02

输入卡密并查询

将购买的卡密粘贴到输入框，点击「查询卡密」。复制时不要带多余空格或换行。

03

核对套餐，选择 Session JSON

查询通过后检查应用名称为 GROK、商品档位与所购套餐一致。选择「Session JSON（推荐）」方式，按页面说明获取账号信息。

04

复制完整 Session JSON

保持 Grok 账号在同一浏览器登录，打开 grok.com/api/auth/session。全选复制完整 JSON，不要只挑选 userId；图中真实内容已遮盖。

05

粘贴 Session，验证账号

回到充值页，将完整 JSON 粘贴进 Session 输入框，点击「验证账号」。请勿删改 JSON 内容。

06

核对账号编号，确认充值

页面进入「确认充值」后，再核对商品档位和账号编号。确认与当前 Grok 账号一致，点击「确认充值」，等待系统处理。

07

看到充值成功

等待页面显示绿色勾号和「充值成功」。处理期间不要重复提交；页面成功后还需要到 Grok 复核结果。

08

回到 Grok 复核订阅和功能

回到 Grok 刷新页面，查看 Grok Bot 是否能进入和使用。再打开设置中的 Billing，检查 SuperGrok 和订阅日期。图中是视频演示账号的结果，不代表所有账号都会相同。

✓

充值完成

常见问题

操作中常见的三个问题

已有订阅或没有 Grok Bot 入口怎么办？

先登录并核实账号支持情况。有订阅时按照充值页面提示确认兼容性；不要把取消旧订阅当作所有人的第一步。

Session JSON 可以发给别人吗？

不可以。Session JSON 可能包含账号会话信息，只在自己的浏览器和充值页面之间完成复制粘贴，不要发送给任何人。

充值后在哪里确认？

回到 Grok 账号设置的 Billing 页面，查看 SuperGrok 状态和下一次计费信息。若页面尚未更新，先刷新，再重新登录检查。
